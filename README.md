# Crown Beauty Salon

Website for Crown Beauty Salon — Hair • Skin • Makeup • Bridal. *Feel like a Queen.*

A single static page (`index.html` + `poster.webp`), no build step.

## Publish with GitHub Pages
Settings › Pages › Source: **Deploy from a branch**, Branch: **main** / **(root)** › Save.
The site appears at `https://<your-username>.github.io/crownbeautysalon/`.
